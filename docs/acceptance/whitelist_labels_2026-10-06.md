# Динамические названия whitelist — 6 октября 2026

## Реализация

Пользовательские кнопки и заголовок: **Трафик в белых списках**.
Название услуги в админке и заявках сохранено отдельно. В пояснениях о
подключении конфиг называется **Белые списки**. Сообщение после отправки
подтверждения оплаты различает начисление трафика и продление подписки.

SubHub публикует `🗒️ Белые списки (9.87/10Гб)`: остаток — подтверждённые
free+paid; знаменатель — объём текущего пакета. Для бессрочных — `(∞)`;
без снимка — `🗒️ Белые списки` без чисел. Делитель 1024³, остаток с двумя
знаками, знаменатель без лишних нулей, округление вниз. Trial: `3.00/3Гб`.

Знаменатель восстанавливается из упорядоченных settled-записей журнала:
выдача и продление устанавливают free_after+paid_after; покупка прибавляет
paid_delta; корректировка задаёт новую базу. Расход/usage_rebase базу не
уменьшают; pending/uncertain не включаются. Старые записи без новых полей
поддержаны по типу операции и paid_after-paid_before. Схема PostgreSQL не менялась.

## Контракт и обновление

`POST /admin/whitelist/traffic`, существующий `X-Admin-Token`:

```json
{"snapshots":[{"panel_email":"synthetic-identity","remaining_bytes":10737418240,"package_bytes":10737418240,"lifetime":false,"as_of":"2026-10-06T12:00:00+00:00","version":2}]}
```

Ответ: `{"updated": N}`; до 200 снимков в запросе. Идентичность casefold,
объёмы — неотрицательные целые байты, timestamp с timezone. Для конечного
пакета remaining не может превышать package. Замена только при большей паре
`(version, as_of_us)`, повтор идемпотентен. VPN-ключи и подписочные токены
не передаются и в логах не выводятся.

Новая таблица SubHub `whitelist_traffic_snapshots` создаётся аддитивно через
существующий init_db/create_all. Настройка сервера:
`traffic_label_mode: whitelist` (по умолчанию none). Домены и ID не хардкодятся.
Снимок меняет node_name и fragment ссылки; тот же node_name использует Happ.

Бот отправляет снимки после очереди и сверки расхода. В production очередь
каждые 30 секунд; пауза между обходами расхода — 15 минут. Открытие раздела
остатка в боте также сверяет расход. Экспорт PostgreSQL использует согласованный
REPEATABLE READ READ ONLY снимок. При отказе следующий цикл повторяет доставку;
оплата не отменяется. На телефоне имя обновляется при обновлении подписки.
